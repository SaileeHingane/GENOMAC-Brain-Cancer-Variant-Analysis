# Jupyter Notebooks

This folder contains the Jupyter Notebook used for downstream analysis of annotated genomic variants generated during the GENOMAC internship project.

## Analyses performed

- Import annotated variant tables
- Filter high and moderate impact variants
- Merge variants across multiple samples
- Extract gene symbols
- Generate gene frequency summaries
- Prepare gene lists for functional enrichment
- Analyse g:Profiler enrichment results
- Create summary visualizations

The notebook demonstrates the Python-based downstream analysis performed after variant annotation done in Galaxy Eu.
