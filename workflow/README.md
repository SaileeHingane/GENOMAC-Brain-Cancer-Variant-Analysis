# Workflow

This folder documents the methodology followed during the GENOMAC genomics internship project using Galaxy Europe.

## Analysis Pipeline

1. Retrieval of publicly available human brain cancer whole genome sequencing (WGS) datasets from NCBI.
2. Quality control of sequencing reads using FastQC.
3. Read trimming and preprocessing.
4. Alignment of reads to the human reference genome (GRCh38).
5. Variant calling.
6. Variant annotation.
7. Python-based filtering of high and moderate impact variants.
8. Gene frequency analysis.
9. Functional enrichment analysis using g:Profiler.
10. Biological interpretation and visualization.

This repository focuses on the bioinformatics workflow and downstream analysis performed during the internship.
